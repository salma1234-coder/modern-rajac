# منصة دراسة التمريض الحديثة | Modern Nursing Study Platform

منصة تعليمية احترافية لطلاب التمريض مع نظام تتبع التقدم، اختبارات تفاعلية، ومؤقت بومودورو.

## ✨ المميزات الرئيسية

### 🎓 للطلاب
- **تسجيل دخول آمن** مع نظام تحقق متقدم
- **واجهة عربية حديثة** مع دعم الوضع الليلي
- **تتبع التقدم** مع إحصائيات مفصلة
- **مؤقت بومودورو** لتحسين التركيز
- **اختبارات تفاعلية** مع نتائج فورية
- **محتوى متعدد الوسائط** (فيديو، صوت، PDF)

### 👩‍🏫 للمدرسين
- **لوحة تحكم متكاملة** لإدارة المحتوى
- **بنك أسئلة** متقدم
- **رفع وسائط** متعددة الأشكال
- **تحليل نتائج** الطلاب
- **نظام تذكير زمني** للمحتوى

### 🔒 الأمان
- **تشفير البيانات** المتقدم
- **حماية من هجمات CSRF**
- **تقييد محاولات الدخول**
- **تحقق من صحة المدخلات**
- **سياسة أمان المحتوى (CSP)**

## 🚀 التثبيت والتشغيل

### المتطلبات
- Node.js 18 أو أحدث
- npm أو yarn
- Docker (اختياري للنشر)

### التشغيل المحلي
```bash
# تثبيت الاعتماديات
npm install

# تشغيل الخادم المحلي
npm start

# افتح http://localhost:3000 في المتصفح
```

### النشر باستخدام Docker
```bash
# بناء وتشغيل الحاويات
docker-compose up -d

# التحقق من الحالة
docker-compose ps
```

## 🐛 حل المشاكل

### مشاكل شائعة
1. **الملفات لا تعمل**: استخدم `npm start` بدلاً من فتح الملف مباشرة
2. **الصوت لا يعمل**: تحقق من صلاحيات المتصفح
3. **الفيديو لا يعرض**: تأكد من حجم الملف أقل من 4MB

### السجلات
```bash
# سجلات الخادم
docker-compose logs nursing-platform

# سجلات Nginx
docker-compose logs nginx
```
